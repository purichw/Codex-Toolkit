# UI/UX Skill Entry Point

Load [SKILL.md](SKILL.md) for user-facing design/implementation/visual QA.
It owns the workflow, source precedence, proportional scope, reference routing,
user preferences, product/shared-component contracts and automatic snapshot gate.

Read only the references triggered by the task. Do not load this entire package
for a tiny edit, run its evaluation suite during ordinary product work, or use
fallback tokens to override an existing brand/system/reference.

[tokens.css](tokens.css) contains optional custom properties only.
[assets/gallery-base.css](assets/gallery-base.css) is a separate, gallery-only
base layer. Neither is a universal design system. The static component gallery
is a visual specimen, not proof that its simulated controls work.

Require current, personally inspected rendered evidence for visual claims.
Structural validation cannot establish taste. Use VERIFIED / PARTIAL / BLOCKED /
FAIL for the stated scope; a disclosed required failure remains a failure.

Skill maintenance and evaluation commands are in
[references/evaluation-protocol.md](references/evaluation-protocol.md).
Use authorized local fixtures only; no implicit permission for paid model runs,
other chats, private data import, production changes, or publishing.
