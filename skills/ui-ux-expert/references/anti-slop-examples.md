# Diagnose Generic Output In Context

A literal CSS match is a prompt to inspect, not a defect verdict. Font families,
gradients, centered text, multiple accents, shadows or pill controls do not
independently establish quality. Respect current user/developer restrictions and
the product's direction; do not turn one correction into a global taste law.

| Observed failure | Check the cause | Small causal repair | Counterexample |
| --- | --- | --- | --- |
| Dashboard looks like marketing | Large display block displaces records; actions compete | Restore task-first hierarchy and comparable rows | Public campaign pages can legitimately prioritize imagery and display type |
| Everything has equal weight | Headings, labels, cards and actions all use the same emphasis | Distinguish content roles through scale, spacing and weight | A deliberately uniform comparison grid may need equal peers |
| Text looks unconsidered | Wrong font loaded, weak role hierarchy, long lines or cramped leading | Fix loaded font and role metrics before replacing the family | Inter/system fonts can be excellent in a well-set interface |
| Centered prose is hard to follow | Long multiline reading without a stable edge | Restore a readable prose axis | This user's stat groups, field names, select values and table headers stay centered |
| Color feels noisy | Decorative accents compete with task/status encoding | Reduce competing emphasis and clarify roles | Multiple chart series or an expressive brand may need several hues |
| UI is boxed and heavy | Containers repeat without semantic boundaries | Remove redundant frames, use unframed groups/bands | Repeated distinct objects and overlays may legitimately have borders plus shadows |
| Button overload | Unrelated actions have equal visual priority | Group by scope and consequence, demote secondary actions | Independent rows may each expose a necessary action |
| Hero says nothing | Generic promise, unclear subject, unrelated media | Show the actual product/place/offer and relevant visual | A reference-led abstract campaign is a different authorized task |
| Fake credibility | Unverified metrics, quotes, logos or charts | Source facts or mark synthetic/unknown content clearly | Synthetic benchmark data is valid when labeled and never presented as real |
| Motion obstructs work | Delayed controls, repeated entrance motion, moving focus context | Remove the delay or motion that obscures state | Purposeful playful motion may fit a game and still needs reduced-motion support |

## Repair Order

Inspect composition and task hierarchy first, then content grouping/geometry,
then type and media, then state/interaction consistency, then optical details.
Do not apply the entire sequence to a tiny known defect. Stop when the requested
scope and its regressions have sufficient evidence.

A before/after pair should retain the same content when claiming a layout
improvement. Replacing broken long text with shorter copy hides the defect.
Show exceptions and tradeoffs, not a single "approved style."
See [composition-and-calibration.md](composition-and-calibration.md) for
synthetic same-content works/fails specimens and their limits.
